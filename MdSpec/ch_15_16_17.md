# Concept

树的定义： 节点（node）加边（edge），且任意两个节点之间只有一条路。等价说法：不能有环。

A tree consists of:
- A set of nodes.
- A set of edges that connect those nodes.
- Constraint: There is exactly one path between any two nodes.


树的高度、深度和平均深度：
- 深度：node离开root的距离。每个节点各有一个深度（depth），根节点的深度为零.
- 高度：最深叶子节点的深度。树的属性，一棵树只有一个高度（height）。
- 平均深度：所有节点深度的平均值就是平均深度（average depth）。


# Binary Search Trees(BST)

`二叉树`: In a rooted binary tree, every node has either 0, 1, or 2 children (subtrees).

`二叉搜索树(BST)`: A binary search tree is a rooted binary tree with the BST property.
- BST Property. For every node X in the tree:
- Every key in the left subtree is less than X’s key.
- Every key in the right subtree is greater than X’s key.

## BST operations

类及方法代码示例如下：
```java
private class BST<Key> {
    private Key key;
    private BST<key> left;
    private BST<key> right;

    public BST(Key key, BST<key> left, BST<key> right) {
        this.key = key;
        this.left = left;
        this.right = right;
    }

    public BST(Key key) {
        this.key = key;
    }

    static BST<key> find(BST<key> T, Key sk) { //contains
        if (T == null)          return null;
        if (sk.equals(T.key))   return T;
        else if (sk < T.key)    return find(T.left, sk);
        else                    return find(T.right, sk);
    }

    static BST<key> insert(BST<key> T, Key ik) {
        if (T == null)              return new BST(ik);
        if (ik < T.key)             T.left = insert(T.left, ik);
        else if (ik > T.key)        T.right = insert(T.right, ik);
        return T;
    }
    
    // delete: Hibbard删除
    // deletion is a bit harder to implement, we won't go over the specifics in this course.
}
```

## BST as Sets and Maps: BST的运用

`java.util`:
- Collection
  - List: Linked List, ArrayList
  - Set: HashSet, TreeSet
- Map: HashMap, TreeMap

用BST实现Set抽象类型：之前使用数组实现过set（ArraySet），这里可以用BST实现set。优势在于，如果树是平衡的，时间复杂度可以达到 Θ(logN), it's faster!

BST实现Map抽象类型：每个BST节点存储(key, value)pairs，即一个键值对。优势在于，如果树是平衡的，时间复杂度可以达到 Θ(logN)

很显然，“树是平衡的”这一前提十分重要。BST实现的数据结构的性能优劣与之息息相关。树是否平衡，关键在于树的高度。

**Big O is not the same as the worst case!**

# B-Trees

## BST的性能局限

随机插入的树，平均深度大概是理想值的 1.4 倍，高度大概是 3 倍。增长阶还在 log 量级，只是常数大。

BST 的性能决定因素是两个数。最坏情况看高度，平均情况看平均深度。而这两个数由插入顺序决定。

## BST局限的解决——B-Trees

不再纠结于树一定要是“二叉”的了，一个节点里可以有k个值和k+1个子节点。每个子节点存着一系列的值（一个区间内的值都放入该节点中）。搜索的原理与BST类似，只是条件分支变多了。

这种结构并不会改变增长阶，所以是可行的。

插入新的数据作为叶子节点会破坏树的平衡性，如何使树一直保持平衡呢？答案是向上推中间值到空位，根满则分裂。意思是说，每个节点有存储上限。达到上限后，把多的值向上沿着父节点传递到有空位的节点。如果一直到根节点都没有空位，此时会分裂根。分裂根会导致整棵树的所有节点都往下挪了一层；分裂叶子或者内部节点的时候，高度一点没变。

这种新的结构就是B-Trees：
- 节点上限为3的树，叫2-3-4树（2-4树），一个节点有2、3或4个孩子
- 上限为2的树，叫2-3树。CS61B电子教材只讲只用2-3树。

B-Trees的运用和缺陷：
- 机制/原理：k 个值管 k+1 段区间；超限就分裂、把中间值推给父节点；级联到有空位的祖先为止；只有根也满了才分裂根、高度 +1。
- with a small L for conceptually balancing search trees, or secondly, with L in the thousands for databases and filesystems with large records.
- B-Trees are really difficult to implement.

# Red-Black Trees

## B-Trees的局限及改进思路

B-Trees在有些方面的性能表现好，但有一点——B-Trees的完整实现非常麻烦困难。

Why not create a tree that is implemented using a BST, but is structurally identical to a 2-3 tree and thus stays balanced?

用二叉搜索树（BST），实现2-3树的效果，难道不可行吗？

可行，只需增加“旋转”。

## Tree Rotation

The formal definition of rotation is:
- `rotateLeft(G)`: Let x be the right child of G. Make G the new left child of x.
- `rotateRight(G)`: Let x be the left child of G. Make G the new right child

```java
private Node rotateRight(Node h) {
    // assert (h != null) && isRed(h.left);
    Node x = h.left;
    h.left = x.right;
    x.right = h;
    return x;
}

// make a right-leaning link lean to the left
private Node rotateLeft(Node h) {
    // assert (h != null) && isRed(h.right);
    Node x = h.right;
    h.right = x.left;
    x.left = h;
    return x;
}
```

假设x是G的右/左子节点。左/右旋转就是：G变成x的左/右子节点。x原先的左/右子节点变为G的右/左子节点。

注意：
- 旋转后仍然为BST，不会破坏BST的性质。
- 旋转既能让增加树的高度，也能降低树的高度.

## Red-Black Trees

**用 BST 实现、结构上等同 2-3 树**。2-3 树能保证树具有平衡性，LLRB与2-3树一一对应，把 2-3 树编码成二叉，所以二叉也能具有自平衡的能力。

这样红黑树（二叉树+红黑链接）基于BST实现不会像B-Tree那样实现困难，又可以通过rotate是自身拥有B-Tree的自平衡能力。且，增长阶一样是log N。

红黑树的红黑指的是节点之间的链接是“红色”还是“黑色”：
- 红黑树与B-Tree之间存在对应关系，链接颜色对应节点值之间的关系。
- 红色链接：胶水链接。被链接的两个节点在对应的B-Tree中是一个节点（两个值分开了）。
- 黑色链接：普通链接。被链接的两个节点在对应的B-Tree中是两个节点。

`左倾红黑树（LLRB）`：六个不变量
- 一个LLRB和一个2-3树唯一对应
- 没有节点有两个红链接
- 左倾红黑树中没有红的右链接
- 根到每片叶子的黑链接数相同：所有叶子同深
- LLRB的高度 ≤ 对应2-3的高度的2倍加1
- LLRB的高度与条目数的log成正比

**LLRB 不是新树，是给 2-3 树换了一套编码——格子变节点、格子里相邻的值变红链接、方向统一朝左。2-3树节点的右元素当父、左元素当左孩子、这条边染红；三个孩子按区间分下去。**。

`左倾红黑树的insertion`：BST insertion -> rotate to proper structure
- Insertion Law：insert the new node with a red link to its parent node.（新插入边永远是红的）
- Insertion Repair:
  - 右边是红链接：rotateLeft(node)
  - 连续两条左红链接（左孩子、左孙子都红链接）：rotateRight(node)
  - 左右都是红：color flip（翻转颜色）

```java
private Node put(Node h, Key key, Value val) {
    if (h == null) { return new Node(key, val, RED); }

    int cmp = key.compareTo(h.key);
    if (cmp < 0)      { h.left  = put(h.left,  key, val); }
    else if (cmp > 0) { h.right = put(h.right, key, val); }
    else              { h.val   = val;                    }

    if (isRed(h.right) && !isRed(h.left))      { h = rotateLeft(h);  }
    if (isRed(h.left)  &&  isRed(h.left.left)) { h = rotateRight(h); }
    if (isRed(h.left)  &&  isRed(h.right))     { h = flipColors(h);  } 

    return h;
}
```
