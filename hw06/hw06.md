# Task 1: BSTMap

Implement the methods in your BSTMap class. The following methods are required:
- void put(K key, V value): Associates the specified key with the value.
- V get(K key): Returns the value that is associated with key.
- boolean containsKey(K key): Returns if this map has a mapping for the given key.
- int size(): Returns the number of key-value mappings.
- void clear(): Removes every mapping from this map.

The iterator, remove, and keySet methods are optional. If you are not implementing them, throw an UnsupportedOperationException.

You can test your implementation using `TestBSTMap.java`.

`put()` method solution:

    BSTMap就是一个名为root的BSTNode。BSTNode有四个属性：key, val, left, right.
    首先想到的是利用递归去解决这一问题：判断当前树的根的key和传入的key之间的大小关系：
        当前树的根为空，更新root为新建的BSTNode节点，size += 1；
        当前树根的key更大，说明应该刚在左子树中；当前树根key更小，说明应该放在右子树中。
        当前树根的key相等，更新key对应的val。size不变。
    
    注意到：
        put是BSTMap的方法。递归中，在左/右子树中put的对象是BSTNode，而BSTNode没有put()！
        因此，需要给BSTNode写一个方法（不可行） or 辅助函数实现递归/高阶函数(上面的递归对应修改)。
    
    put()方法返回值为void，所以方法内只执行操作，不return。现在的重点就在于辅助函数的实现。

    辅助函数的功能/作用是什么？这是首先要思考的问题。我们新写一个辅助函数的目的是为了在BSTNode对象上也能put。也就是说：辅助函数的功能是给名为root的BSTNode对象添加指定的键值对。在Java中存在重载的机制，所以辅助函数也可以命名为put。当然，其他名字也可以。

    put()函数的功能确定清楚了，接下来就是函数的参数和返回值。功能室给指定的BSTNode添加键值对，所以要知道节点是哪一个、键值对的值，即node, key, value。从修改node的功能，也可以看出返回值应为修改后的node，即BSTNode类。

    函数签名已经完整，只剩下函数体了。无非是实现递归，而怎么递归在最开始已经思考过了。不同就在于返回值不同导致的具体细节不同：不同分支，更新node的不同属性（有的是node.val or node.left or node.right） or 新增一个节点返回。
